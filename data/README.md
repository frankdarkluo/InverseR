# Local data directory

This directory is reserved for raw inputs and versioned derived datasets generated by the
InverseR CLI. Data payloads are intentionally ignored by Git.

Typical local subdirectories include:

- `pilot-v0/` or another versioned synthetic development run;
- `snookerVideos/` for a pinned raw-source snapshot;
- `Billiard-dataset/` for researcher-supplied author data;
- `structured/`, `processed/`, `quality/` and `research/` for derived records.

Do not add media or derived labels to Git merely because they are technically accessible.
Check the source-specific licence, attribution, processing and redistribution permissions in
[`configs/sources.json`](../configs/sources.json) and the
[data documentation](../docs/data/data_card.md).
